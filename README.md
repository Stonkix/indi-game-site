# DUNGEON PUNK

> Gachi remixes. **Loud. Fast. No rules.**

Сайт-каталог гачи-ремиксов в стиле DIY-зина и ксерокс-панка.
Чистые HTML + CSS + JavaScript (ES-модули), без фреймворков, без сборки, без трекеров.

---

## 1. Запуск

Открывать `index.html` двойным кликом **нельзя** — браузер заблокирует `fetch('tracks.json')`
из-за политики `file://`. Нужен любой статический сервер.

```bash
# из корня проекта
python -m http.server 8000
# затем открой http://localhost:8000
```

Альтернативы:

```bash
npx serve .
php -S localhost:8000
```

Сборка не требуется: сервер просто раздаёт файлы.

## 2. Как добавить свои треки

### 2.1. Положить файлы

```
assets/audio/my-remix.mp3
```

Формат: MP3 / OGG / WAV / M4A — всё, что играет браузер.
Рекомендуется MP3 128–192 kbps: 3 минуты ≈ 3 МБ.

### 2.2. Дописать объект в `tracks.json`

> Файл в поставке сжат в одну строку ради веса страницы. Для правок это не мешает:
> форматирование JSON на чтение не влияет, а валидность проверяется любым линтером.
> Хотите обратно «красиво» — `python -m json.tool tracks.json` или prettier по вкусу.

```json
{
  "id": "t13",
  "title": "Название ремикса",
  "artist": "Ваш ник",
  "bpm": 174,
  "duration": 165,
  "tags": ["punk", "hardcore"],
  "src": "assets/audio/my-remix.mp3",
  "added": "2026-09-28",
  "votes": 0
}
```

| Поле       | Тип      | Комментарий                                                          |
| ---------- | -------- | -------------------------------------------------------------------- |
| `id`       | string   | Уникальный. От него детерминированно генерируется обложка и узор.    |
| `title`    | string   | Название                                                             |
| `artist`   | string   | Автор ремикса                                                        |
| `bpm`      | number   | Используется слайдером BPM и сортировкой                             |
| `duration` | number   | Секунды (подпись на карточке; реальная длина берётся из файла)       |
| `tags`     | string[] | Любые, но чипы фильтра строятся из списка `TAGS` в `app.js`          |
| `src`      | string   | Путь к аудио относительно `index.html`                               |
| `added`    | string   | `YYYY-MM-DD`, для сортировки «Новые»                                 |
| `votes`    | number   | Стартовые голоса. Локальный голос устройства прибавляется сверху     |

### 2.3. Свои теги

Откройте `app.js`:

```js
const TAGS = ['punk', 'hardcore', 'pop-punk', 'ska-punk', 'oi!'];
```

Добавьте/уберите значения — чипы и фильтрация обновятся автоматически.

### 2.4. Демо-файл

`assets/audio/demo.wav` — синтезированный панк-луп (178 BPM, 8 тактов), чтобы сайт
звучал «из коробки». Это заглушка: замените `src` у треков на свои файлы и удалите
её, когда она больше не нужна.

## 3. Кастомизация

### 3.1. Палитра

Всего четыре цвета — в начале `styles.css`:

```css
:root {
  --ink:   #0a0a0a;   /* чёрный       */
  --paper: #f2efe6;   /* грязно-белый */
  --acid:  #f5e400;   /* кислотный    */
  --red:   #e10600;   /* красный      */
}
```

Меняйте значения — перекрасится всё, включая обложки (они используют те же токены
только если вы поправите их в `coverMarkup()` в `app.js`; там цвета заданы HEX-ами
внутри SVG, чтобы работали в любом контексте).

### 3.2. Шрифты

Подключены в `<head>` `index.html`:

- `Rubik Spray Paint` / `Rubik Glitch` — логотип и ransom-буквы
- `Special Elite` — основной текст
- `Permanent Marker` — акценты и «рукописные» подписи
- `Bebas Neue` — кнопки, навигация, цифры

Чтобы сменить — замените `@family=` в ссылке Google Fonts и переменные:

```css
--f-logo, --f-glitch, --f-type, --f-marker, --f-btn
```

### 3.3. Ransom-note заголовки

Любой элемент с `data-ransom="ТЕКСТ"` автоматически превращается в рваные буквы:
каждая получает свой шрифт, фон, поворот ±4° и сдвиг. Достаточно дописать атрибут:

```html
<h2><span class="ransom" data-ransom="НОВЫЙ БЛОК">НОВЫЙ БЛОК</span></h2>
```

### 3.4. Обложки

Генерируются в `coverMarkup()` — 6 детерминированных SVG-паттернов по `hash(id)`:
полосы + халфтон, молния, усилитель, цепи, силуэт с ирокезом, кассета. Никаких
внешних картинок: всё векторное, оригинальное, весит 0 КБ. Хотите больше вариантов —
добавьте ветку в `if/else` и увеличьте `h % 6`.

### 3.5. Дворовые автоматы

Блок `#arcade` — три оригинальных мини-гейма на канвасе, без сторонних движков и ассетов:

- **слева «Шахта 13»** — копатель: копай стрелками/WASD, собирай медяки, обходи и не подкапывай
  камни (они падают), дойди до люка. Уровни бесконечные, каждый сложнее.
- **справа «Панк-птица»** — летун: пробел / ↑ / тап — взмах, пролетай между усилителями.
  Рекорд хранится в `localStorage` (`dp.arcade.best.v1`).
- **«Барабаны»** — ритм-игра: четыре дорожки (`D F J K`, стрелки или тапы), ноты падают в такт
  BPM **играющего трека** (если ничего не играет — демо-темп 150). Окна: «в точку» ±60 мс,
  «норм» ±150 мс, дальше — мимо. Комбо, точность, оценка S/A/B/C по итогу 16 тактов.
  Рекорд — `dp.arcade.drums.v1`. Метроном и удары озвучены через отдельный `AudioContext`
  (осцилляторы + шумовой буфер), без внешних сэмплов.

Чтобы играть в барабаны в такт конкретному треку — сначала включи его в плеере, потом жми
«В такт»: игра подхватит `bpm` из `tracks.json`.

Технически:

- игры рисуются на `<canvas>` четырьмя цветами палитры, шрифты — `Permanent Marker` / `Special Elite`;
- игровой цикл на `requestAnimationFrame` **останавливается**, когда блок вне экрана
  (`IntersectionObserver`) — это важно для Lighthouse и батареи;
- управление с канваса перехватывается через `stopPropagation`, поэтому стрелки не скроллят
  страницу и не перематывают плеер; глобальные горячие клавиши при этом не конфликтуют;
- на тач-устройствах у копателя есть кнопки-стрелки, у птицы — тап по экрану.

Баланс правится константами в `app.js`: гравитация `1500`, импульс взмаха `-430`, скорость
усилителей `158`, зазор `92`, в копателе — `cols/rows`, скорость падения камней (0.28 с),
награды за землю/медяк/уровень.

### 3.6. Бит-машина (`#studio`)

Секвенсор на 16 шагов и 8 дорожек. Это **не** FL Studio и не пытается им быть — но бит
собрать можно: бочка, пластик, тарелка, хлопок, том, бас, аккорд, шум.

- **Синтез полностью на месте.** Ни одного сэмпла: осцилляторы (sine / triangle / saw / square),
  шумовой буфер и `WaveShaper` для «грязи». Мастер-цепочка: gain → waveshaper → компрессор.
- **Тайминг** — классический lookahead-планировщик: `setInterval(25 ms)` раскладывает шаги
  на ±120 мс вперёд по часам `AudioContext`, а подсветка колонки идёт через `requestAnimationFrame`.
  Поэтому свинг не «плывёт» от нагрузки на CPU.
- **Контролы:** темп 50–220, свинг 0–60 %, громкость, «грязь», тоника (E/G/A/D), пресеты
  (Панк, Хардкор, Ска-панк, Oi!, Просто шум), случайный бит, BPM из играющего трека, очистка,
  экспорт JSON.
- **Сохранение** — `dp.studio.v1` в `localStorage` (сетка + все контролы), пишется с дебаунсом.
- **Ленивая загрузка**: `studio.js` (~18 КБ) приезжает через динамический `import()` за 400 px
  до появления секции на экране. Без этого основная страница вылезала за бюджет 150 КБ.
- Кнопка «BPM из трека» берёт темп у дорожки, которая сейчас в плеере.

Свои пресеты добавляются в `S_PRESETS` (`studio.js`) — формат простой: 16 символов на дорожку,
`x` — удар, `.` — тишина.

### Пасхалка: грязь 105%

Ползунок «Грязь» специально размечен до **105%**. Дотянешь до упора — сайт осыпается:
карточки, автоматы, плеер и манифест разлетаются вниз со случайным вращением, включается
тряска, шумовой обвал и падающий тон, а снизу выезжает табличка «ВЫКРУТИЛ. СЛОМАЛ.» с кнопкой
«ПОЧИНИТЬ». Ремонт возвращает грязь на 25%, а перезагрузка страницы тоже считается починкой
(аварийное значение в `localStorage` не восстанавливается).

Реализация: `studio.js` → `overdrive()` / `repair()`; анимации — `fallAway`, `dirtDive`,
`chaosShake` в `styles.css`; смещения и вращение задаются индивидуально через
`--fall-x / --fall-r / --fall-d / --fall-i`. При `prefers-reduced-motion` падение отключается,
остаются только табличка и звук. События `dp:overdrive` / `dp:repaired` глушат плеер и автоматы.

### 3.7. Боковые панели: мыло справа, драка слева

Обе панели — декор на канвасе, нарисованный кодом, без картинок и библиотек.
Живут в `rails.js`, собираются в рантайме (разметка + стили) и включаются кнопками
в доке внизу по центру.

**Справа — «режем мыло».** Нож режет брусок: летит стружка, отрезанный кусок
отваливается, цикл повторяется.

**Слева — «67 vs ТУН-ТУН».** Двое стоят: цифры-наклейка и бревно с битой (персонажи
оригинальные). Ткнёшь по панели или жмёшь «НАЧАТЬ ДРАКУ» — они сбегаются, начинается
потасовка со искрами, звёздами и подписями «БАМ / ХРЯСЬ / ТУН», после чего сайт
разносит в клочья: карточки, автоматы, бит-машину и плеер сдувает вниз. Снизу выезжает
табличка «ДРАКА! САЙТ РАЗОБРАЛИ» с кнопкой «ПОЧИНИТЬ» — она собирает всё обратно,
и драчуны расходятся по углам.

- **Раскладка.** На экранах ≥ 1560 px панели стоят в свободных полях по бокам
  (контент ограничен 1200 px, так что ничего не перекрывается). Ниже — превращаются
  в компактные панели в нижних углах, над доком и плеером. На мобильных ещё меньше.
- **Включение.** Кнопки «🥊 67 vs ТУН-ТУН» и «🧼 РЕЖЕМ МЫЛО» в доке внизу.
  Состояние — `dp.rails.v1`, обе включены по умолчанию.
- **Производительность.** `rails.js` (~29 КБ) не входит в стартовую загрузку.
  Кадры ограничены ~30 fps, при `visibilitychange` анимации встают.
- **`prefers-reduced-motion`.** Рисуется один статичный кадр, драки и падения нет.

### 3.8. Алкошоп «ГРАДУС» в шапке (`gradus.js`)

В шапке, по центру, пристраивается фасад вымышленного алкошопа: козырёк, мигающая
неоновая вывеска, витрина с бутылками и двое граждан нетрезвого вида, которые
покачиваются, отхлёбывают и метают бутылки.

- **Бутылки падают на сайт.** Полноэкранный канвас-оверлей (`pointer-events: none`)
  считает физику: бутылка летит, бьётся о «пол» (линия над плеером), рассыпается
  на осколки, оставляет лужу и подпись «ЗВЯК!». Иногда сверху прилетает плевок
  с «ТЬФУ!».
- **Ткнуть по фасаду** — нальют ещё: три бутылки сразу и ускоренный темп на пару секунд.
- **Погоня.** Раз в 20–45 секунд оба выбегают из лавки и носятся друг за другом вдоль шапки:
  пыль, подскоки, «ДОГОНЯЙ!». Тот, что впереди, спотыкается, задний в него влетает —
  и оба разбиваются. Они **фарфоровые**, поэтому это звон, черепки и подпись «ФАРФОР!»,
  без крови и чернухи.
- **Люди падают, как бутылки.** Раз в 4–10 секунд из двери выходит гражданин, перегибается
  через край и летит вниз — по той же физике, что и бутылки: кувыркаясь, с отскоком,
  а внизу бьётся на черепки («ФАРФОР!», «ХРУСТЬ!», «ОЙ!»). Крови нет: они фарфоровые.
- **Коты на козырьке.** Два чёрных кота сидят на козырьке, машут хвостом и раз в 4–9 секунд
  скидывают бутылку вниз с «МЯУ!» — классика жанра.
- **«🧹 ПОДМЕСТИ»** в доке убирает осколки и лужи.

Что сюда сознательно не попало: физиологические сцены, кровь и расчленёнка. Тон сайта —
мемный юмор, а не чернуха, поэтому «разбиваются» они как посуда.
- **Звук** — синтез (шумовой «звяк» с полосовым фильтром, «бульк», «тьфу»).
  Стартует после первого клика: до жеста браузер `AudioContext` не будит.
- **`18+`** прямо на вывеске, а сам фасад — шарж из зина, не реклама.
- На экранах уже 940 px фасад не показывается (в шапке нет места), но бутылки
  летят из-за кадра — панель по-прежнему можно включать кнопкой.
- **Производительность**: ~30 fps, DPR ограничен 1.25, при `visibilitychange`
  цикл встаёт; при `prefers-reduced-motion` рисуется статичный фасад без физики.

### 3.9. Суши-бар «РОЛЛ-МАСТЕР» в шапке (`sushi.js`)

Справа в шапке — ещё одно заведение: повар в бандане за прилавком с роллами.
Он периодически метает ролл через **весь экран**: тот летит по дуге справа налево
и шлёпается об пол с подписью «ШЛЁП!», разлетаясь рисом и кусочками нори.

- **Ткнуть по витрине** — метнут ролл посильнее и подальше.
- Пятна от роллов **убираются сами**: у каждого своя скорость угасания, мусор
  не копится бесконечно (жёсткий лимит — 90 кусочков).
- Звук синтезирован: «вжух» на броске (пила вверх) и «шлёп» (шум через
  низкочастотный фильтр).
- Место в шапке есть только на экранах **≥ 1400 px** — правая часть занята
  навигацией и «Тише/Громче», поэтому модуль ещё и поджимает `padding-right`
  у шапки. Ниже этого порога витрина прячется, но роллы всё равно летят
  из-за кадра, а включить их можно кнопкой в доке.

> Персонажи и вывески вымышленные. Название было предложено другое, с грубым
> словом на вывеске — такое в проекте не появляется: сайт про музыку и мемы,
> а не про оскорбления.

### 3.10. «ОГОРОД 13» в самом низу страницы (`garden.js`)

Башенная защита по дорожкам: 5 грядок × 8 клеток, зомбаки идут справа налево
к вашему гаражу. **Жанр взят, реализация своя**: растения, зомбаки, вывеска
и вся графика — оригинальные, нарисованы кодом. Чужих персонажей и логотипов
нет, крови тоже: зомбака попросту выкорчёвывают.

- **Растения** (ставятся кнопкой, дальше тычком по клетке; горячие клавиши `1 2 3`):
  - `1 · ЧЕРТОПОЛОХ` — стреляет семечками по своему ряду, 14 урона;
  - `2 · ПРОБКА` — стена на 380 HP, ничего не делает, зато держит;
  - `3 · ГРИБ` — раз в 2.6 с рвёт всё живое вокруг себя и исчезает;
  - `4 · ВЫКОРЧЕВАТЬ` — лопата, убирает растение с клетки.
- **Зомбаки**: обычный, бегун с ирокезом и кабан в кожанке. Грызут растения,
  дошедшие до гаража — конец партии. Волны растут: чаще, злее, толще.
- **Экономики нет.** Вместо солнца/монет — кулдаун на каждый вид растения,
  он же рисуется полоской на кнопке. Так проще играть с телефона.
- Счёт — выкорчёванные зомбаки (кабан идёт за трёх), рекорд — `dp.garden.best.v1`.
- `IntersectionObserver` ставит игру на автопаузу, когда блок уехал с экрана,
  и сам снимает её при возвращении. Пробел — пауза вручную.
- Секция собирается в рантайме и вставляется в конец `<main>` (то есть в самый
  низ страницы), а заголовок получает ransom-буквы через событие `dp:ransom`,
  которое слушает `app.js`.

### 3.11. «НОЧНАЯ СМЕНА» под огородом (`shift.js`)

Ночной обход с камерами: шесть часов до утра, четыре камеры, ящик пива и панки,
которые очень хотят пить. **Жанр взят, реализация своя** — никаких аниматроников
и чужих вывесок, только свои панки.

- **Двор → Гараж → Склад → Будка.** Панки входят во двор и по таймеру (6–14 с)
  подбираются к складу. Дошёл до будки — шесть секунд на спасение, потом пиво выпито.
- **Ткни по панку** — прилетит бутылка. Здоровый панк отступает на комнату назад,
  обычный вырубается. Бутылок шесть на смену, промах тоже тратит заряд.
- **Заряд** тает сам (0.9 %/с) плюс 2.5 % за переключение камеры. Сел в ноль —
  камеры слепнут, а панки ускоряются вдвое. Пережить всё равно можно.
- **Шесть часов × 13 секунд.** Дожил — ночь зачтена, счётчик ночей растёт
  (`dp.shift.best.v1`). Стартовые сутки становятся злее каждую ночь.
- **Псевдо-3D.** Настоящего 3D нет: в кадре точка схода и коэффициент глубины `z`,
  всё дальнее стягивается к центру и мельчает. Комната рисуется коридором
  (`drawCorridor` — потолок, пол, стены, направляющие по полу), реквизит ставится
  через `put(x, y, z)`, панки идут от дальних к ближним и растут в размере.
  Сверху — лёгкий CSS-наклон `rotateX(2.4deg)` с медленным покачиванием камеры.
- **Скримеры.** Панк на весь экран с криком «ХОЙ!!»: свой полноэкранный канвас
  (`z-index 99000`), разгон масштаба, тряска и красная вспышка. На провале смены —
  большой (1.9 с), при заходе панка в будку — короткий (0.8 с) и не чаще раза
  в три секунды, чтобы не превращалось в стробоскоп. Звук: синтезированный рёв
  (пила вниз + шум) плюс попытка произнести «Хой!» через `speechSynthesis`; если
  голоса в системе нет, остаётся рёв. При `prefers-reduced-motion` тряска отключается.
- Управление: кнопки камер (`1 2 3 4`), пробел — пауза, клик по панку — бутылка.
  `IntersectionObserver` ставит на автопаузу, когда блок уехал с экрана.
- Секция вставляется **строго под «Огород 13»**: загрузчик в `app.js` ждёт
  завершения первого импорта и только потом тянет второй.

### 3.12. «САМОКАТ 13» — конструктор тачки (`kart.js`)

Ставишь детали в сетку, жмёшь «ПОЕХАЛИ» — и смотришь, доедет ли твоя тачка до флага.
**Жанр взят, реализация своя**: ни чужих персонажей, ни чужих интерфейсов.
Мелодия тоже своя — простой марш в до-мажоре, 132 BPM, восемь тактов, написан
специально для этого модуля; ничьи темы не цитируются и не имитируются.

- **Детали:** `РАМА` (скелет), `КОЛЕСО`, `МОТОР`, `БАЛЛОН` (тянет вверх), `ГРУЗ`
  (прижимает). Лимиты на каждую, остаток виден на кнопке.
- Деталь можно поставить только вплотную к раме — связность проверяется обходом
  от базовой клетки, так что «висящих в воздухе» колёс не бывает.
- **Физика честная, но маленькая:** одно твёрдое тело (масса, момент инерции),
  каждое колесо — пружина с демпфером плюс сила сцепления по касательной к уклону.
  Мотор крутит колёса; если тачка перевернулась (`|угол| > 1.9`), мотор глохнет.
  Шаг 1/200 с, до 24 подшагов в кадр — поэтому не разваливается на кочках.
- **Три уровня:** прямая с бугром, яма (нужен баллон или разгон) и горка, куда без
  второго мотора не заехать. Стрелки подталкивают и наклоняют, `R` — разобрать.
- **Музыка:** свой мини-секвенсор на `AudioContext` (квадрат — мелодия, треугольник —
  бас), сетка восьмыми, планировщик с опережением. Кнопка «♪ Музыка» глушит.
- Секция вставляется **после «Ночной смены»**, загрузчик ждёт предыдущие модули.

### 3.13. Общий холст для мусора (`overlay.js`)

«ГРАДУС» и «РОЛЛ-МАСТЕР» рисуют в **один** полноэкранный канвас. Модуль даёт
метод `getOverlay()`, который возвращает:

- `env` — общая геометрия `{ vw, vh, floor, dpr }`, где `floor` — линия над плеером,
  о которую бьётся всё падающее;
- `add(drawer)` / `remove(drawer)` — регистрация отрисовщика `{ step(dt), draw(ctx, env) }`;
- `measure()` и `poke()`.

Один `requestAnimationFrame` на всех, 30 fps, пауза при `visibilitychange`,
DPR ограничен 1.25. Когда отрисовщиков нет — цикл стоит. Именно поэтому
третий полноэкранный холст не появился: до рефакторинга каждый магазин тащил свой.

### 3.14. «Разнос сайта» (`chaos.js`)

Одна общая механика на два повода: ползунок «Грязь» на 105% (бит-машина) и драка
на левой панели. `chaos.js` — ленивый модуль, потому что нужен сразу двум фичам.

- Инжектит свои стили (`fallAway`, `dirtDive`, `chaosShake`, `machineHop`) и разметку
  таблички — на стартовой странице их нет.
- Разбрасывает элементы со случайным сдвигом, вращением и задержкой через
  `--fall-x / --fall-r / --fall-d / --fall-i`.
- Играет шумовой обвал + падающий тон через свой `AudioContext`.
- События `dp:overdrive` / `dp:repaired` глушат плеер; бит-машина по `dp:repaired`
  возвращает грязь на 25%, а драчуны — в стойку.

## 5. Подключение бэкенда

Сейчас форма — заглушка, которая пишет заявки в `localStorage`. Точка подключения
одна: функция `submitTrack()` в `app.js` (есть комментарий `BACKEND:`).

```js
async function submitTrack(payload) {
  const res = await fetch('/api/tracks', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload)
  });
  if (!res.ok) throw new Error('HTTP ' + res.status);
  renderSubmissions();
}
```

Голоса тоже можно вынести на сервер: `POST /api/vote { id }` вместо `state.votes`.
Каталог уже подгружается из `tracks.json` — при переезде на API достаточно заменить
`fetch('tracks.json')` на `fetch('/api/tracks')`, схема объектов та же.

## 6. Доступность и производительность

- Семантика: `header` / `main` / `section` / `nav` / `footer`, `aria-live` для плеера и счётчика.
- Фокус: жирная жёлтая обводка `:focus-visible` (4px), видимая на всех интерактивных элементах.
- Контраст: текст — чёрный на бумаге (≈ 17:1), жёлтый на чёрном (≈ 15:1), красный — только
  как фон под белым текстом (≈ 5:1) или для крупных акцентов.
- `prefers-reduced-motion` отключает зерно, бегущие строки, тряску и визуализатор
  (он становится статичным рисунком).
- Курсор-маркер включается только на устройствах с точным указателем (≥ 900 px),
  на тач-экранах остаётся системный.
- Аудио: `preload="none"`, обложки генерируются лениво через `IntersectionObserver`.
- Страница без аудио — заметно меньше 150 КБ. Внешних трекеров нет: только Google Fonts.
